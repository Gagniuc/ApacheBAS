Important conventions

True comparisons produce -1. Decimal values are stored with up to six fractional digits. File paths are relative to the .bas application.

Syntax

Comments

#
Syntax
' comentariu
REM comentariu

A line beginning with an apostrophe or REM is ignored by the interpreter.

Example 1
' This is a comment
PRINT "Hello"
Example 2
REM BASIC-style comment
A = 10
Syntax

String literals

#
Syntax
"text"

Strings are enclosed in quotation marks. Use two consecutive quotation marks to include one quotation mark inside a string.

Example 1
PRINT "ApacheBAS"
Example 2
PRINT "He said ""Hello""."
Syntax

Numeric literals

#
Syntax
123
-45
3.141593
&HFF
&O377
&B1010

Signed integers, decimals with up to six fractional digits, and hexadecimal, octal, or binary literals are supported.

Example 1
PRINT &HFF        
PRINT &O10        
PRINT &B1010
Example 2
A = 12.5
PRINT A * 2
Syntax

Scalar variables

#
Syntax
NAME = expression
NAME$ = expression

Names are case-insensitive. By convention, the $ suffix indicates a string value.

Example 1
AGE = 42
NAME$ = "Paul"
PRINT NAME$; " are "; AGE; " ani"
Example 2
TOTAL = 10 + 20
MESSAGE$ = "Total=" & STR$(TOTAL)
Syntax

Labels and line numbers

#
Syntax
label:
100 statement

A line may begin with a named label or a classic line number. These targets can be used by GOTO and GOSUB.

Example 1
start:
PRINT "Pornire"
GOTO finish
finish:
PRINT "Final"
Example 2
10 PRINT "First line"
20 GOTO 40
30 PRINT "Skipped"
40 PRINT "Done"
Statement

Assignment

#
Syntax
variable = expression
array(index) = expression

Evaluates the expression on the right and stores the result in a scalar variable or an array element.

Example 1
A = 2 + 3 * 4
PRINT A
Example 2
DIM NAMES$(1 TO 2)
NAMES$(1) = "Ana"
NAMES$(2) = "Paul"
Statement

PRINT

Alias: ?#
Syntax
PRINT [expression [;|, expression] ...] [;]
? expression

Sends text to the response. A semicolon joins output without a separator, a comma adds a space, and PRINT without a trailing semicolon adds CR/LF.

Example 1
PRINT "Name: "; NAME$
PRINT "Age:", AGE
Example 2
PRINT "Same line: ";
PRINT "continued"
Example 3
? "PRINT prescurtat"

Flow control

14 entries
Statement

IF ... THEN ... ELSE

#
Syntax
IF condition THEN statement [ELSE statement]

Single-line IF form. Zero is false; any nonzero value is true.

Example 1
AGE = 20
IF AGE >= 18 THEN PRINT "Adult" ELSE PRINT "Minor"
Example 2
IF GET_NAME$ = "" THEN NAME$ = "Guest" ELSE NAME$ = GET_NAME$
Statement

FOR ... NEXT

#
Syntax
FOR variable = start TO end [STEP step]
    ...
NEXT [variable]

Repeats a block with a positive or negative step. The default step is 1, and STEP 0 causes an error.

Example 1
FOR I = 1 TO 5
    PRINT I
NEXT I
Example 2
FOR I = 10 TO 2 STEP -2
    PRINT I; " ";
NEXT I
Statement

WHILE ... WEND

#
Syntax
WHILE condition
    ...
WEND

Tests the condition before each iteration.

Example 1
I = 1
WHILE I <= 3
    PRINT I
    I = I + 1
WEND
Statement

DO WHILE / DO UNTIL

#
Syntax
DO WHILE condition
    ...
LOOP

DO UNTIL condition
    ...
LOOP

Pre-test forms. WHILE repeats while the condition is true; UNTIL repeats until it becomes true.

Example 1
I = 0
DO WHILE I < 3
    PRINT I
    I = I + 1
LOOP
Example 2
I = 0
DO UNTIL I = 3
    I = I + 1
LOOP
PRINT I
Statement

LOOP WHILE / LOOP UNTIL

#
Syntax
DO
    ...
LOOP WHILE condition

DO
    ...
LOOP UNTIL condition

Post-test forms; the body executes at least once.

Example 1
I = 0
DO
    I = I + 1
    PRINT I
LOOP WHILE I < 3
Example 2
DO
    R = RND
LOOP UNTIL R > 0.8
PRINT R
Statement

DO ... LOOP

#
Syntax
DO
    ...
LOOP

Unconditional loop. Exit it with GOTO, STOP, or END.

Example 1
I = 0
DO
    I = I + 1
    IF I = 3 THEN GOTO done
LOOP
done:
PRINT I

INPUT

#
Syntax

Statement

DIM

#
Syntax
DIM declaration [, declaration ...]

Declares scalar variables or one-dimensional arrays. Explicit bounds and AS clauses are supported; AS STRING creates string storage.

Example 1
DIM A(10), NAMES$(1 TO 5)
Example 2
DIM SCORE AS INTEGER, TITLE AS STRING
DIM B(-2 TO 2) AS INTEGER
Statement

OPTION BASE

#
Syntax
OPTION BASE 0
OPTION BASE 1

Sets the default lower bound for arrays declared with a single bound. It must appear before the first array DIM.

Example 1
OPTION BASE 1
DIM A(3)
PRINT LBOUND(A); ".."; UBOUND(A)

DATA

#
Syntax
DATA value [, value ...]

Defines textual values later retrieved by READ. Quoted strings lose their outer quotation marks.

Example 1

#
Syntax
READ target [, target ...]

Transfers the next DATA values into scalar variables or array elements.

Example 1
DIM A(1 TO 3)

READ A(1),A(2),A(3)

#
Syntax

Moves the DATA cursor back to the first item. RESTORE with a label is not implemented in this version.

Template

<?= ... ?>

#
Syntax
<?= expression ?>

Evaluates and inserts the expression directly into the response. For user-supplied text, explicitly use HTML$.

Example 1
<p>Server time: <?= TIME$ ?></p>
Example 2
<p>Name: <?= HTML$(GET_NAME$) ?></p>
File mode

Pure BASIC file

#
Syntax
PRINT "..."

A file without template tags is interpreted as a BASIC program, except for a pure HTML include beginning with <.

Example 1
PRINT "@@CONTENT-TYPE text/html; charset=utf-8"
PRINT "<h1>ApacheBAS</h1>"

INCLUDE

#
Syntax
INCLUDE path_expression

Includes a .bas or .inc file relative to the application directory. Included code uses the same variable scope; mixed templates are also supported.

Absolute paths and .. are rejected.

The maximum include size is 512 KiB; the maximum depth is 8.

Example 1
INCLUDE "includes/header.inc"
PRINT "<main>Content</main>"
INCLUDE "includes/footer.inc"
Example 2
PART$ = "parts/menu.bas"
INCLUDE PART$
Statement

WRITEFILE

#
Syntax
WRITEFILE path, content

Creates or replaces a file under the data/ directory. The result is reported through FILE_*.

Example 1
WRITEFILE "data/message.txt", "Hello"
IF FILE_OK THEN PRINT FILE_PATH$ ELSE PRINT FILE_ERROR$
Example 2
WRITEFILE "data/user.json", "{""name"":""Paul""}"

SAVEUPLOAD

#
Syntax
SAVEUPLOAD file_name

Saves the raw binary request body in uploads/. It accepts PNG, JPG/JPEG, GIF, and WEBP, and verifies both the extension and signature.

The body must be sent as application/octet-stream or image/*.

The current body limit is 1 MiB.

Example 1
SAVEUPLOAD "photo.png"
IF UPLOAD_OK THEN PRINT UPLOAD_URL$ ELSE PRINT UPLOAD_ERROR$

EXEC

#
Syntax
EXEC executable [, argument]

Launches an .exe without a shell, captures stdout and stderr, waits for at most 5 seconds, and publishes the result through EXEC_*.

A simple name is searched first beside the .bas file and then through Windows search, including System32/PATH.

A single optional text argument is supported.

EXEC_OUTPUT$ can contain up to 1,048,575 bytes in v0.1.34.3.

Example 1
EXEC "netstat.exe", "-ano"
IF EXEC_OK THEN PRINT "<pre>"; HTML$(EXEC_OUTPUT$); "</pre>" ELSE PRINT EXEC_ERROR$
Example 2
EXEC "tool.exe"
PRINT EXEC_CODE
Result variable

START

#
Syntax
START executable [, argument]

Starts a Windows application normally and returns immediately. It does not capture output, wait, or terminate the process.

A single optional text argument is supported.

For a visible window, Apache must run in an interactive Windows session.

Example 1
START "viewer.exe"
Example 2
START "apps\g2.exe", "document.txt"
IF START_OK = 0 THEN PRINT START_ERROR$
