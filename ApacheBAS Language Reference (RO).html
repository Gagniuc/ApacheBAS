Program BASIC pur

PRINT "@@CONTENT-TYPE text/html; charset=utf-8"
NAME$ = GET_NAME$
IF NAME$ = "" THEN NAME$ = "Guest"
PRINT "<h1>Salut "; HTML$(NAME$); "</h1>"

Șablon mixt

<!doctype html>
<h1>Salut <?= HTML$(GET_NAME$) ?></h1>

Cum se folosește

Caută după numele unei funcții sau după o idee precum „upload”, „buclă”, „JSON” ori „proces”. Fiecare intrare are sintaxă și exemple copiable.

Convenții importante

Comparațiile adevărate produc -1. Valorile zecimale sunt păstrate cu maximum șase cifre fracționare. Căile de fișiere sunt relative la aplicația .bas.

Nu există intrări care corespund căutării.

Sintaxă

Comentarii

#
Sintaxă
' comentariu
REM comentariu

O linie care începe cu apostrof sau cu REM este ignorată de interpret.

Exemplu 1
' Acesta este un comentariu
PRINT "Salut"
Exemplu 2
REM Comentariu în stil BASIC
A = 10
Sintaxă

Literali șir

#
Sintaxă
"text"

Șirurile sunt delimitate prin ghilimele. Pentru o ghilimea în interior se folosesc două ghilimele consecutive.

Exemplu 1
PRINT "ApacheBAS"
Exemplu 2
PRINT "El a spus ""Salut""."
Sintaxă

Literali numerici

#
Sintaxă
123
-45
3.141593
&HFF
&O377
&B1010

Sunt acceptate numere întregi semnate, zecimale cu până la șase cifre fracționare și literali hexazecimali, octali sau binari.

Exemplu 1
PRINT &HFF        
PRINT &O10        
PRINT &B1010
Exemplu 2
A = 12.5
PRINT A * 2
Sintaxă

Variabile scalare

#
Sintaxă
NUME = expresie
NUME$ = expresie

Numele sunt tratate fără diferență între litere mari și mici. Sufixul $ indică în mod convențional o valoare de tip șir.

Exemplu 1
AGE = 42
NAME$ = "Paul"
PRINT NAME$; " are "; AGE; " ani"
Exemplu 2
TOTAL = 10 + 20
MESSAGE$ = "Total=" & STR$(TOTAL)

Etichete și numere de linie

#
Sintaxă
label:
100 statement

O linie poate începe cu o etichetă numită sau cu un număr de linie clasic. Aceste ținte pot fi folosite de GOTO și GOSUB.

Exemplu 1
start:
PRINT "Pornire"
GOTO finish
finish:
PRINT "Final"
Exemplu 2
10 PRINT "Prima linie"
20 GOTO 40
30 PRINT "Sărită"
40 PRINT "Gata"

Atribuire

#
Sintaxă
variabilă = expresie
tablou(index) = expresie

Evaluează expresia din dreapta și stochează rezultatul într-o variabilă scalară sau într-un element de tablou.

NAMES$(1) = "Ana"

PRINT

Alias: ?#
Sintaxă
PRINT [expresie [;|, expresie] ...] [;]
? expresie

Trimite text în răspuns. Punctul și virgula concatenează fără separator, virgula adaugă un spațiu, iar un PRINT fără ; final adaugă CR/LF.

Exemplu 1
PRINT "Nume: "; NAME$
PRINT "Vârstă:", AGE
Exemplu 2
PRINT "Aceeași linie: ";
PRINT "continuare"
Exemplu 3
? "PRINT prescurtat"

Instrucțiune

IF ... THEN ... ELSE

#
Sintaxă
IF condiție THEN instrucțiune [ELSE instrucțiune]

Formă IF pe o singură linie. Condiția zero este falsă; orice valoare diferită de zero este adevărată.

Exemplu 1
AGE = 20
IF AGE >= 18 THEN PRINT "Adult" ELSE PRINT "Minor"
Exemplu 2
IF GET_NAME$ = "" THEN NAME$ = "Guest" ELSE NAME$ = GET_NAME$
Instrucțiune

FOR ... NEXT

#
Sintaxă
FOR variabilă = început TO sfârșit [STEP pas]
    ...
NEXT [variabilă]

Repetă un bloc cu pas pozitiv sau negativ. Pasul implicit este 1, iar STEP 0 produce eroare.

Exemplu 1
FOR I = 1 TO 5
    PRINT I
NEXT I
Exemplu 2
FOR I = 10 TO 2 STEP -2
    PRINT I; " ";
NEXT I
Instrucțiune

WHILE ... WEND

#
Sintaxă
WHILE condiție
    ...
WEND

Testează condiția înainte de fiecare iterație.

Exemplu 1
I = 1
WHILE I <= 3
    PRINT I
    I = I + 1
WEND
Instrucțiune

DO WHILE / DO UNTIL

#
Sintaxă
DO WHILE condiție
    ...
LOOP

DO UNTIL condiție
    ...
LOOP

Forme cu test înaintea corpului. WHILE repetă cât timp condiția este adevărată; UNTIL repetă până când devine adevărată.

Exemplu 1
I = 0
DO WHILE I < 3
    PRINT I
    I = I + 1
LOOP
Exemplu 2
I = 0
DO UNTIL I = 3
    I = I + 1
LOOP
PRINT I
Instrucțiune

LOOP WHILE / LOOP UNTIL

#
Sintaxă
DO
    ...
LOOP WHILE condiție

DO
    ...
LOOP UNTIL condiție

Forme cu test după corp; corpul este executat cel puțin o dată.

Exemplu 1
I = 0
DO
    I = I + 1
    PRINT I
LOOP WHILE I < 3
Exemplu 2
DO
    R = RND
LOOP UNTIL R > 0.8
PRINT R
Instrucțiune

DO ... LOOP

#
Sintaxă
DO
    ...
LOOP

Buclă necondiționată. Ieșirea se face prin GOTO, STOP sau END.

Exemplu 1
I = 0
DO
    I = I + 1
    IF I = 3 THEN GOTO done
LOOP
done:
PRINT I

GOSUB / RETURN

#
Sintaxă
GOSUB etichetă
...

Șablon

#
Sintaxă
<?bas
    cod BASIC
?>

Într-un fișier mixt, execută blocul BASIC și păstrează restul HTML literal.

</html>

INCLUDE

#
Sintaxă
INCLUDE expresie_cale

Include un fișier .bas sau .inc relativ la directorul aplicației. Codul inclus folosește același spațiu de variabile; sunt acceptate și șabloane mixte.

Căile absolute și .. sunt respinse.

Dimensiunea maximă a unui include este 512 KiB; adâncimea maximă este 8.

PART$ = "parts/menu.bas"
INCLUDE PART$

Instrucțiune

EXEC

#
Sintaxă
EXEC executabil [, argument]

Lansează un .exe fără shell, capturează stdout și stderr, așteaptă maximum 5 secunde și publică rezultatul în EXEC_*.

Un nume simplu este căutat întâi lângă fișierul .bas și apoi prin căutarea Windows, inclusiv System32/PATH.

Este acceptat un singur argument textual opțional.

EXEC_OUTPUT$ poate conține până la 1.048.575 octeți în v0.1.34.3.

Exemplu 1
EXEC "netstat.exe", "-ano"
IF EXEC_OK THEN PRINT "<pre>"; HTML$(EXEC_OUTPUT$); "</pre>" ELSE PRINT EXEC_ERROR$
Exemplu 2
EXEC "tool.exe"
PRINT EXEC_CODE

Instrucțiune

START

#
Sintaxă

Pornește normal o aplicație Windows și revine imediat. Nu capturează ieșirea, nu așteaptă și nu oprește procesul.
